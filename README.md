# Interactive Word Graph

An interactive web-based data visualization tool built with Next.js and React. It displays the relationships between English words, synonyms, and related phrases using a dynamic node graph.

## Features
- **Dynamic Node Graph:** Visualizes complex word relationships.
- **Sentiment Slider:** Filters words by emotional polarity.
- **Clean UI:** Minimalist and responsive design.

## Tech Stack
- Frontend: HTML, CSS, JavaScript (Next.js / React)
- Data: Open-source dictionary datasets
